Пользователь учится по курсу **Теория Автоматического Управления (ТАУ)**.

## Темы из конспектов

### Пространство состояний
- Уравнения: $\dot{x} = Ax + Bu$, $y = Cx$
- Матрица управляемости: $P = (B \; AB \; A^2B \; \ldots)$, проверка $\det P \neq 0$
- Синтез регуляторов: подбор $k_1, k_2, \ldots$ по желаемым полюсам
- Устойчивость по собственным значениям матрицы A (все Re < 0)
- Функция Ляпунова для анализа устойчивости

### Передаточные функции и Лаплас
- $W(s) = \frac{Y(s)}{X(s)}$
- Разложение на простые дроби → обратное преобразование Лапласа
- Структурные схемы: последовательное, параллельное, с ОС
- $W_{пол} = \frac{W_1 W_2}{1 + W_1 W_2 W_{ос}}$

### Анализ ошибок (астатизм)
- $k_x = \lim_{s\to0} W(s)$ (позиционный коэффициент)
- $k_v = \lim_{s\to0} s\cdot W(s)$ (скоростной)
- $k_a = \lim_{s\to0} s^2\cdot W(s)$ (ускорение)
- Установившаяся ошибка: $\varepsilon_x = \frac{1}{1+k_x}$, $\varepsilon_v = \frac{1}{k_v}$
- Порядок астатизма = количество интеграторов в $W(s)$

### Критерии устойчивости
- Критерий Гурвица: все коэффициенты характеристического полинома > 0 + условия на миноры матрицы Гурвица
- Критерий Рауса (табличный)

### Электрические цепи в ТАУ
- $U_R = R\cdot i$, $U_C = \frac{1}{C}\int i\,dt$, $U_L = L\frac{di}{dt}$
- RLC-цепи → передаточные функции через Лаплас

## Схема оформления решений (из конспектов)
1. Записать уравнения состояния / передаточную функцию
2. Составить матрицы (A, B, C или P, Q)
3. Вычислить det → вывод об управляемости/наблюдаемости
4. Найти собственные значения или применить критерий Гурвица
5. Вычислить коэффициенты ошибки и порядок астатизма
6. Нарисовать структурную схему
