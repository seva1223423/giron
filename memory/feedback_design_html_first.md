# Дизайн HTML-first — постоянное правило (2026-06-03)

**Любая дизайн/UI-работа в Giron начинается с HTML-макета в правой Preview-панели Claude Code, ДО написания React Native кода.** Пользователь явно попросил, чтобы все новые чаты это делали по умолчанию.

## Порядок (строгий)
1. Сделать HTML-вариант(ы) в `docs/design/variants/` (новый `*.html` или обновить существующий). 2–4 варианта одного экрана рядом, реальные цвета Direction A (графит `#0E0E0F`/`#17171A` + золото `#D4B07A`), реальный русский текст.
2. Открыть его в Preview-панели справа (инструмент превью `preview_start` на локальный `.html`).
3. Предложить варианты в чате коротко («A / B / C»), дать выбрать. Не угадывать молча.
4. Только после выбора — реализовать в RN через `design` sub-agent.

## Почему
HTML-макет в превью = мгновенная итерация (секунды vs пересборка APK). Пользователь принимает визуальное решение ДО кода, не переделываем готовый RN-экран. Так уже делали для панели Тренировок (`docs/design/variants/v1…v5.html`).

## Когда пропустить HTML-шаг
Микро-правки (один отступ/цвет/текст), не-визуальные изменения, явная просьба «без макета, сразу код».
