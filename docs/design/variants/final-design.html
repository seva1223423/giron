Мои шаблоны и библиотека программ — твоё замечание: обе ленты остаются на виду, программы показаны обложками, их выбирают глазами. Журнал подходов без кнопок и барабан — из набора по вводу: строка стала данными, а не пультом. Отдых полосой — чтобы пауза не выключала приложение. Итог с рекордом — единственное место, где уже сейчас всё правильно, его не трогаем, только добавляем «сохранить как шаблон», замыкая круг: тренировка → шаблон → завтра в один тап.
