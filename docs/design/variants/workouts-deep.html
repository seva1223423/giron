Два разбора нашли 45 проблем по всему приложению и 31 в разделе тренировок. Здесь — варианты для пяти самых больных экранов. Зелёным снизу подсвечена зона большого пальца, красным сверху — куда одной рукой не дотянуться.

Макет, не приложение. Выбираешь — реализую.

6Итог

Связка: 1A + 2A + 3A + 4A + 5A. «Сегодня» отвечает, что тренировать. Журнал подходов помещается на экран, вес меняется в один тап, засчитанный подход можно исправить. Отдых больше не блокирует экран. Из четырёх понятий остаются два — «Тренировка» и «Программа». Программа создаётся копией готовой за 2 тапа.

Отдельно, вне макетов, но обязательно: подключить три мёртвых экрана (История, Календарь, Рекорды — они уже написаны), починить «Повторить тренировку» и рассинхрон библиотеки (список берёт упражнения с сервера, деталь ищет в локальном файле → «Упражнение не найдено»).
