# Giron — философия дизайна

**Название движения:** Закалённая сдержанность (Tempered Restraint)

**Дата:** 2026-05-23
**Контекст:** написана после deep design audit. Дополняет (не заменяет) Direction A токены из `src/theme/colors.ts` и rules из `.claude/agents/design.md`. Токены — что использовать. Эта страница — **почему так**, и **что отличает наш дизайн от AI-генерации**.

---

## Манифест

Мы строим инструмент для людей которые ходят в тренажёрный зал по программе три раза в неделю и держат счёт в граммах. Они не пользователи. Они спортсмены. Им не нужны мотивационные карточки и геймификация — у них уже есть мотивация. Им нужно знать **вес. подходы. время отдыха. что дальше.** Быстро. Чётко. Без шума.

Поэтому наш дизайн — это **закалённая сдержанность.** Эстетика хороших швейцарских часов Patek Philippe Calatrava — а не Hublot. Кожаного блокнота для тренировок — а не iPad-приложения. Японской чайной комнаты — а не Las Vegas. Каждый миллиметр оправдан. Ничего лишнего. Каждая деталь — результат сотни итераций.

**Золото — редкое.** Как сусальное золото в иконе. Один акцентный гольд (`#D4B07A`) на экране. Никогда не два. Когда видишь золото — это значит «вот это важно». Если золото везде — оно не значит ничего.

**Числа — тяжёлые.** Цифры с дайв-часов: монопространственные, толстые, контрастные. Когда между подходами стоишь со штангой в руках — должен прочитать вес за полсекунды без очков. 40pt, weight 700, **dark on gold**. Не 16pt grey-on-dark.

**Пустота — намеренная.** Японский принцип `ma` — пространство имеет вес. Один заголовок, одна цифра, одна кнопка. Это не недоделано. Это **довершено.**

**Голос — личный.** Это не «Калории». Это «Сегодня осталось 340 ккал — на йогурт хватит». Это не «Программа». Это «Понедельник: грудь, последний раз был 4 дня назад». Каждая надпись — как от тренера который тебя знает. Никаких generic-лейблов из AI-чекбокса.

## Шесть признаков AI-генерации (banned patterns)

Если делая экран ты ловишь себя на одном из этих — стоп. Это AI-tell.

### 1. Карточный паттерн «Icon + Title + Subtitle» повторённый 5 раз
**Симптом:** все секции выглядят одинаково: серая карточка, иконка слева, заголовок жирным, подзаголовок мелким серым. Это паттерн который генерирует любой LLM по умолчанию.
**Лекарство:** разные блоки должны выглядеть **по-разному.** Hero-stat — большой, тёплый, центрированный. Список — компактный, утилитарный. Промо-блок — асимметричный, с акцентом. Не все блоки равны. Один главный. Остальные — поддерживают.

### 2. Дословные generic заголовки
**Симптом:** «Сегодня», «Статистика», «Программа», «Тренировки/нед.», «Калории» — это лейблы которые буквально называют содержимое. AI пишет именно так.
**Лекарство:** **редакторские заголовки.** Вместо «Сегодня» → «Понедельник. Грудь.» Вместо «Калории» → «340 осталось». Вместо «Программа» → «Жим. 4 недели до 100 кг.» Заголовок должен **рассказывать.**

### 3. Дублирующиеся CTA
**Симптом:** «Начать тренировку» в трёх местах на одном экране — большая золотая карточка в центре + floating FAB снизу + кнопка в header. Это значит что дизайнер не решил **какая** кнопка главная.
**Лекарство:** одна primary CTA на экран. Остальные — secondary outline или icon-only. Если их 2 — значит ты не определился. Определись.

### 4. Generic loaders (`ActivityIndicator` крутящийся)
**Симптом:** системная крутилка в дефолтном цвете на тёмном фоне. Выглядит как браузер 2008-го.
**Лекарство:** наш `<Spinner color={colors.primary} />`. На некоторых экранах — **skeleton placeholders** в форме контента. На критичных моментах (стрим AI) — **typing dots** с золотой пульсацией. Загрузка — это часть бренда, а не пауза.

### 5. Все элементы одинаково «важные»
**Симптом:** на экране 5 карточек одного размера, одного шрифта, одного цвета. Глаз не знает куда смотреть.
**Лекарство:** **3-уровневая иерархия.** Hero (1 элемент, 2× размера, doer-attention). Primary (3-5 элементов, обычный размер). Tertiary (хинты, метки, мелкое). Соотношение 1 : 3 : ∞.

### 6. Скучные state-переходы
**Симптом:** кнопка нажалась — opacity упала на 0.7. Таймер досчитал до нуля — просто исчез. Сет завершён — галочка появилась.
**Лекарство:** **state-aware дизайн.** Кнопка нажалась — spring scale 0.96 + haptic. Таймер последние 5 секунд — pulse + vibrate. Сет завершён — micro-burst анимация на чекмарке. Каждое состояние — мини-событие.

## Шесть техник premium-команды

То что AI-генератор не сделает по умолчанию, но делает уважающий себя дизайнер.

### 1. Гольд-halo на primary CTA
Не просто `backgroundColor: colors.primary`. **Свечение вокруг кнопки:**
```ts
shadowColor: colors.primary,
shadowOpacity: 0.35,
shadowRadius: 16,
shadowOffset: { width: 0, height: 0 },
elevation: 8,
```
Кнопка выглядит как будто **светится изнутри.** На тёмном фоне это даёт «вес» которого нет у плоской заливки. Дайв-часы в темноте.

### 2. Hairline gold divider
Между секциями — не `1px solid border`. **Волосяная линия gold с 12% alpha:**
```ts
<View style={{ height: 1, backgroundColor: colors.primary + '20', marginVertical: spacing.lg }} />
```
Едва видно. Но даёт ощущение что секции **разделены намеренно,** не просто прокручены.

### 3. Слоёная глубина (layered depth)
Не один уровень surface. **Два:**
- `colors.surface` (#17171A) — базовая карточка
- `colors.surfaceElevated` (#1E1E22) — приподнятая

Карточка-в-карточке создаёт depth без shadow. Дешевый эффект — но крайне эффективный на dark mode.

### 4. metaLabel над hero числом
Не «Калории: 1850». **Маленький уппер-кейс metalabel сверху + большое число под ним:**
```tsx
<Text style={[typography.metaLabel, { color: colors.textSecondary }]}>СЕГОДНЯ · КАЛОРИИ</Text>
<Text style={[typography.number, { color: colors.text }]}>
  1850 <Text style={[typography.body, { color: colors.textSecondary }]}>ккал</Text>
</Text>
```
Это паттерн с приборной панели Bentley. Не Apple Watch. Не Garmin Connect. **Bentley.**

### 5. Состояния как мини-события (state-as-event)
Когда состояние меняется — **празднуй это:**
- Сет завершён → 200ms scale-up чекмарка с spring + haptic.success()
- PR установлен → particle burst, 1.5s celebration overlay
- Таймер досчитал → full-screen flash 200ms перед скрытием
- AI стримит → typing dots → live cursor → completion ripple

Не делай переходы плавно-незаметными. Делай их **заметно-радостными.**

### 6. Russian typography refinements
**Кавычки:** «ёлочки», не `"straight"`. Внутренние — „двойные нижние“.
**Тире vs дефис:** `—` для пауз в предложениях. `-` для составных слов.
**Неразрывные пробелы:** `5 кг`, `100 г`, `10 мин` — не должны разрываться.
**Сокращения:** `мин.`, `кг`, `мл`, `ккал`, `₽`. Короткая форма всегда — `12 дн.` а не `12 дней` в плотном UI.

Эти детали невидимы пока их нет. Но когда они **есть** — глаз цепляется и думает «над этим долго работали.»

## Структурный принцип: 3-секундный тест

Открываю экран → закрываю глаза на 3 секунды → что осталось в памяти?

**Если ничего — экран провален.** Это означает что нет hero. Нет личности. Нет единственного гвоздя который вбивается в память.

**Если что-то конкретное** (число, фраза, цвет) — экран сделан правильно.

Не строй экран как «набор информации». Строй как **постер с единственной идеей в центре.** Всё остальное — обслуживание этого центра.

Когда в будущем спавнится дизайн-агент или приходит новый Claude — **первым делом он читает этот файл.** Тогда между сессиями не теряется голос. Direction A токены отвечают «что цвет primary». Эта философия отвечает **«что значит premium для Giron».**

> «Я бы поставил это в Patek Philippe? Или в Hublot?»

Patek — закалённая сдержанность. Hublot — кричащая роскошь. Мы — Patek.
